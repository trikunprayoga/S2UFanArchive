CARA MENJALANKAN
1. Ekstrak folder.
2. Masukkan aset sesuai nama file di atas.
3. Buka index.html di browser.

Jika audio tidak berjalan saat file HTML dibuka langsung:
jalankan folder lewat local server, misalnya ekstensi Live Server di VS Code.
